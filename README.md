# Pymes

Este repositorio está dividido en dos generaciones deliberadamente aisladas:

- [`v1/`](v1/) es la fotografía histórica e inmutable del producto anterior.
- [`v2/`](v2/) es la nueva implementación horizontal, construida desde cero.

El código de `v1/` se conserva únicamente como referencia. No recibe fixes,
actualizaciones, CI ni despliegues. Todo desarrollo nuevo pertenece a `v2/` y
consume capacidades reutilizables publicadas desde
[`platform`](https://github.com/devpablocristo/platform).

La hoja de ruta y el registro de decisiones viven en [`docs/v2/`](docs/v2/).
